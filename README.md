# 2026 신입생 대상 알고리즘 경진대회 Backend

2026 신입생 대상 알고리즘 경진대회의 제출·채점·운영 기능을 자체 구현하는 백엔드 저장소입니다.

## 현재 상태

현재는 구현 전 준비 단계이며, 아래 기능은 구현 목표입니다.
ZOJ는 동작 원리만 참고하며 소스를 재사용하지 않습니다.

## 구현 목표

- 인증: 참가자와 운영자의 인증 및 권한 처리
- 대회: 대회 정보와 진행 상태 관리
- 문제: 문제 지문과 테스트 자료 관리
- 제출: 참가자의 코드와 사용 언어 접수
- 채점 처리: 제출 코드 실행과 판정
- 결과: 채점 상태와 최종 결과 조회
- 순위: 대회 규칙에 따른 순위 집계
- 운영: 대회 운영에 필요한 관리 기능

지원 목표 언어는 C, C++, Python, Java이며, 지원 버전은 미정입니다.

## 기술 스택 및 실행

기술 스택, 채점 에이전트, 실행 환경은 BE 담당자 2명이 결정합니다.
설치 방법과 실행 방법은 해당 결정 후 작성합니다.
API 명세를 공유할 위치는 확정 후 이 README에 추가합니다.

## 협업

- `main`을 기준 브랜치로 사용합니다.
- 기능은 `feat/submission`, 수정은 `fix/judge-error`처럼 작업 브랜치를 만들어 진행합니다.
- PR에 변경 내용과 확인 방법을 작성합니다.
- 다른 팀원 1명의 확인을 받은 뒤 `main`에 병합합니다.
- API 형식 변경은 FE·BE 담당자 간에 먼저 공유합니다.

관련 저장소: frontend (React 기반 프론트엔드)

공개 저장소이므로 운영 키·비밀번호·실제 `.env`·참가자 개인정보·미공개 문제 자료는 커밋하지 않습니다.
